# MexGym 1.2

Esta actualización incorpora mejoras para que la contratación de una suscripción sea más clara y confiable.

## Precios siempre actualizados

- Los nuevos pagos con Mercado Pago utilizan el precio vigente configurado para cada plan.
- Las promociones disponibles se aplican correctamente antes de abrir el pago.
- Si un proceso pendiente conserva un precio anterior, MexGym te permitirá actualizarlo antes de continuar.
- Los clientes que ya cuentan con una suscripción conservan las condiciones de su precio contratado.

## Mejoras generales

- Mensajes más claros durante el proceso de pago.
- Ajustes de estabilidad para mantener una experiencia segura y consistente.

La actualización conserva toda la información y configuración del gimnasio.
