# MexGym 1.3.0

- Nueva identidad comercial MexGym.
- Nuevo icono oficial con fondo negro y pesas verdes.
- Cada gimnasio puede subir, previsualizar o restablecer su logo desde Configuración.
- Nuevo sistema de actualizaciones automáticas.
- Descarga y verificación segura de nuevas versiones.
- Opción para actualizar ahora, recordar más tarde o consultar las notas.
- Respaldo automático de la versión anterior.
- Reapertura automática de MexGym después de instalar.
