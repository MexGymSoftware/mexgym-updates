# MexGym 1.1

Más tranquilidad para la operación diaria, con respaldos constantes y un acceso biométrico capaz de recuperarse automáticamente.

## Respaldos siempre preparados

- La carpeta elegida queda guardada inmediatamente y ya no se solicita en cada respaldo.
- Si todavía no se configuró una ubicación, MexGym utiliza automáticamente **Documentos → MexGym → Respaldos**.
- La aplicación comprueba cada 30 minutos que exista el respaldo cifrado del día, incluso si la laptop permanece abierta.
- **Crear respaldo ahora** guarda directamente en la ubicación configurada.

## Acceso biométrico más confiable

- El lector se reconecta automáticamente después de suspender y reanudar Windows.
- Las conexiones USB obsoletas se liberan sin necesidad de reiniciar la computadora.
- La supervisión continua recupera capturas interrumpidas aunque la ventana esté minimizada o en segundo plano.

## Continuidad y protección

- Se mantienen hasta 30 días de respaldos automáticos cifrados.
- Mejoras generales de estabilidad para equipos que permanecen encendidos durante jornadas prolongadas.
