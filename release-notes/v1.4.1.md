# MexGym 1.4.1

Una actualización enfocada en presentar cada novedad de forma más clara y agradable dentro de la aplicación.

## Experiencia visual

- Nuevo diseño para las notas de actualización.
- Títulos, secciones y listas con una presentación más limpia y organizada.
- Área de lectura ampliada para consultar cómodamente todos los cambios.

## Navegación segura

- Las novedades se muestran directamente dentro de MexGym.
- No se abren páginas externas al consultar las notas.
- Mejoras internas de estabilidad en el flujo de actualización.
